# Contributing to Krewire.com

This guide covers contributing to the official website and documentation portal (`github.com/krewire/krewire.com`).

## Language & Conventions

- All content, documentation, components, and commit messages must be in **English**.
- The site is built with Krewire `.kiw` DSL and compiled with `kiw build`.
- Local development: `kiw serve` or `kiw dev`.
