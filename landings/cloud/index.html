Three Pillars

Secure. Sustainable. Scalable.

Krewire Cloud brings the ecosystem's founding architectural contract directly to production operations. Every capability is verified against independent quality and security gates.

🛡 Pillar 01

Secure by Default

Strict tenant isolation, zero root privileges, memory and process ceilings, encrypted secrets reference, and automated TLS termination keep the attack surface minimal and verifiable.

🌱 Pillar 02

Sustainable Operations

Single static Go binaries with embedded assets, zero external daemon bloat, low-footprint supervisor, and instant rollback. Runs reliably on a $5 VPS or bare-metal servers.

⚡ Pillar 03

Progressive Scalability

Additive growth without rewriting. Host-based reverse proxying, dynamic port management, multi-node clustering, and per-tenant metered bandwidth from dev to enterprise.

Platform Capabilities

The Boring Parts of Production, Handled

Build, supervision, routing, and quotas are decoupled modules with single responsibilities — ensuring failures stay strictly contained and upgrades stay predictable.

🏢

Multi-Tenant Control Plane

Tenants, projects, environments (dev, prod), and deployment histories live in one store with tenant-scoped isolation and quota enforcement.

📦

Hermetic Builds

Every release is compiled with CGO_ENABLED=0, trimmed, and stripped into an immutable binary artifact with zero host toolchain surprises.

🔍

Process Supervisor

Automatic port allocation, active health probes (/healthz), crash loops detection, bounded restarts, and memory ceilings for every workload.

🔄

Zero-Downtime Blue/Green

Traffic only switches after the new instance passes live health checks. The retired instance drains gracefully with SIGTERM without dropping requests.

🌐

Host-Based Gateway

Register a hostname and internal port at deploy time. The edge proxy hot-reloads routes dynamically and owns TLS termination with automated renewal.

📊

Quotas & Metering

Plan limits for projects, memory, CPU time, and bandwidth are evaluated per tenant in real time, with usage records ready for audit and billing.

Deterministic Pipeline

A release is a sequence you can read

Nothing is hidden behind opaque black boxes. Every lifecycle stage writes a structured event line and a deployment status you can inspect.

  • Builds and releases are tracked per commit and per tenant.
  • Failed health probes never receive ingress production traffic.
  • Live log streaming via WebSocket and persistent journal.
  • Instant rollback to the last verified stable release.
  1. 01 · Connect & Push Point a project at a Git repository or trigger a release directly via kiw deploy --cloud, API, or webhook.
  2. 02 · Hermetic Compile The runner compiles a stripped static binary with CGO_ENABLED=0 and captures the immutable SHA-256 digest.
  3. 03 · Supervise & Probe The process boots on an isolated port; the supervisor polls /healthz until green.
  4. 04 · Route Hot-Swap & Drain The gateway switches edge traffic with zero dropped packets, while the retired instance drains gracefully.
Unified Ergonomics

Configured in krewire.yaml. Managed with kiw.

No scattered Dockerfiles, Helm charts, or obscure CI scripts. Your entire cloud configuration lives in the same file as your local development environment.

krewire.yaml 
# Single source of truth for cloud deployments
project:
  name: payment-service
  kind: service

cloud:
  tenant: acme-corp
  env: production
  port: auto
  health:
    path: /healthz
    interval: 5s
  limits:
    memory: 512MB
    max_restarts: 5
