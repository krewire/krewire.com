Capabilities

A workspace built for humans and agents

Every subsystem of Dash exists to make autonomous work safe, observable, and reversible — inside a boundary you control.

Sandboxed runtimes

Per-tenant execution environments with path-traversal prevention, CPU, memory, and storage quotas enforced at the boundary.

Autonomous Krew agents

Embed the Krew agent loop directly in the sandbox to inspect, refactor, and verify code — with a human review gate before anything ships.

Real-time collaboration

WebSocket presence tracks who is online, which file they have open, and where their cursor is — across distributed teams.

Interactive automation terminal

A low-latency PTY runner for builds, test suites, and scripts — with timeout guards and full output capture inside the workspace boundary.

Safe virtual filesystem

Browse, read, and atomically write project files through a sandboxed FS layer that refuses to escape the workspace root.

Ecosystem by design

Ships with Krewire Auth for SSO, MFA, and RBAC, and hands finished workloads to Krewire Cloud for deployment.

Workflow

From empty folder to reviewed change

Dash keeps humans in control of the loop. Agents do the repetitive work; you approve the diff.

  • No local toolchain to install — the workspace runs in the sandbox.
  • Every agent action is attributable, auditable, and reversible.
  • The same environment a teammate sees is the one your agent edits.
  1. Provision Create an isolated workspace from a repository with quotas and a known-good runtime.
  2. Collaborate Invite teammates; presence and open-file state sync in real time over WebSocket.
  3. Automate Task a Krew agent to refactor, test, or integrate. Watch each step stream into the terminal.
  4. Review & ship Inspect the diff, run verification, then deploy the workload through Krewire Cloud.
