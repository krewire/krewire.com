# Web UI Components & Design System (`github.com/krewire/ui`)

Import path: `github.com/krewire/ui`

Krewire UI is a zero-dependency, neo-brutalist ("pop-brutalist") design system and Single-File Component library built natively for the Krewire Go ecosystem.

---

## 1. Design Philosophy

1. **Own Your Components (shadcn Distribution Model)**:
   Components live directly inside your project's `components/` directory as editable `.kiw` files. There is no opaque JavaScript bundle or closed runtime dependency.
2. **Zero Runtime JavaScript Bloat**:
   Interactive components prioritize semantic HTML primitives (`<details>`, `<summary>`, `<dialog>`, form elements). Minimal vanilla JavaScript is used only where native browser events require it (such as outside-click dismissal).
3. **High-Contrast Pop-Brutalist Visuals**:
   - Signature pop-borders (`2px` to `2.5px` solid border tokens).
   - Hard offset box-shadows (`2px 2px`, `4px 4px`, `6px 6px`) without fuzzy blur.
   - High-contrast color hierarchy ensuring full WCAG AA/AAA compliance.
4. **Deterministic Token Cascading**:
   Component styles inherit from single-sourced CSS custom properties. Overriding a token at `:root` or on a container element instantly cascades down the DOM tree.

## 2. Design Tokens System (`krewire-ui.css`)

Krewire UI defines a standardized set of semantic tokens:

### Semantic Colors
```css
:root {
  --primary: #39D353;           /* Vivid emerald green */
  --primary-content: #0B1F3B;   /* High-contrast midnight navy text */
  --secondary: #00D1C1;         /* Bright cyan */
  --secondary-content: #0B1F3B;
  --accent: #FF3B2E;            /* Alert crimson */
  --accent-content: #ffffff;
  --success: #39D353;
  --warning: #ffb703;           /* Amber gold */
  --error: #FF3B2E;             /* Alert red */
  --info: #00D1C1;              /* Informational cyan */
}
```

### Surfaces & Dark Mode Inversion
```css
:root {
  --bg: #FAF8F4;                /* Base alabaster cream */
  --bg-2: #f2ede4;              /* Subtle elevated surface */
  --bg-3: #e8e2d5;              /* Bordered card container */
  --fg: #0B1F3B;                /* Primary midnight text */
  --muted: #57677d;             /* Secondary descriptive text */
  --border: #0B1F3B;            /* Pop-brutalist border color */
}

:root[data-theme="dark"], html[data-theme="dark"], .dark {
  --bg: #0B1F3B;                /* Midnight navy background */
  --bg-2: #112646;              /* Elevated dark surface */
  --bg-3: #1a3865;              /* Card background */
  --fg: #FAF8F4;                /* High-contrast cream text */
  --muted: #9ab0ce;             /* Muted dark text */
  --border: #FAF8F4;            /* Pop-brutalist light border */
}
```

### Pop-Brutalist Borders & Shadows
```css
:root {
  --pop-border: 2.5px solid var(--border);
  --pop-border-thin: 2px solid var(--border);
  --pop-shadow-sm: 2px 2px 0px var(--border);
  --pop-shadow: 4px 4px 0px var(--border);
  --pop-shadow-lg: 6px 6px 0px var(--border);
  --radius: 10px;
}

:root[data-theme="dark"], html[data-theme="dark"], .dark {
  --pop-shadow-sm: 2px 2px 0px var(--primary);
  --pop-shadow: 4px 4px 0px var(--primary);
  --pop-shadow-lg: 6px 6px 0px var(--primary);
}
```

## 3. Component Registry (66 Components)

Krewire UI includes 66 Single-File Components divided into functional categories:

### 3.1 Navigation & Structure
- `<Navbar />`: Main application header with brand mark, responsive desktop navigation, and drawer toggle.
- `<NavMenu />`: Accessible navigation bar with interactive dropdown support.
- `<Sidebar />`: Collapsible sidebar navigation for documentation manuscripts and admin panels.
- `<Breadcrumb />`: Hierarchical page breadcrumb navigation.
- `<Tabs />`: Accessible content switcher supporting persistent active states.
- `<Pagination />`: Numbered pagination bar with next/prev buttons.
- `<Drawer />`: Smooth sliding overlay panel for mobile navigation.
- `<Hamburger />`: Animated 3-line hamburger menu toggle button.
- `<Brand />`: Scalable ecosystem logo and version badge.

### 3.2 Actions & Buttons
- `<Button />`: Core interactive button supporting `primary`, `secondary`, `accent`, `outline`, and `ghost` variants.
- `<ButtonGroup />`: Grouped set of buttons with unified borders and segment control.
- `<Dropdown />`: Interactive menu built on native `<details>` and `<summary>` elements with outside-click dismissal.
- `<ActionMenu />`: Compact contextual action menu for table rows and cards.
- `<Fab />`: Floating Action Button for prominent primary screen actions.

### 3.3 Feedback & Status
- `<Alert />`: Contextual notification banner supporting `info`, `success`, `warning`, and `error` states.
- `<Banner />`: Full-width prominent announcement bar with dismiss trigger.
- `<Toast />`: Lightweight transient notification toast.
- `<Badge />`: Micro-indicator badge with color variants.
- `<Tag />`: Removable or selectable keyword tag.
- `<Progress />`: Determinate and indeterminate loading bar.
- `<Spinner />`: Accessible animated SVG loader spinner.
- `<Skeleton />`: Shimmer placeholder for content loading states.
- `<Empty />`: Empty-state placeholder with icon, message, and call-to-action button.

### 3.4 Data Display & Content
- `<Card />`: Elevated container with header, body, and footer slots.
- `<Stat />`: Key performance indicator and numeric metric display with trend indicators.
- `<Table />`: Responsive data table with striped, bordered, and hover states.
- `<Accordion />`: Expandable/collapsible content panels with keyboard accessibility.
- `<Timeline />`: Sequential vertical activity event stream.
- `<CodeWindow />`: macOS-style terminal window with traffic light buttons and copy-to-clipboard button.
- `<Terminal />`: Compact single-line command preview terminal.
- `<Avatar />`: User profile image with fallback initials.
- `<Kbd />`: Keyboard shortcut visual indicator.
- `<Divider />`: Visual horizontal or vertical separator with optional label.

### 3.5 Forms & Inputs
- `<Input />`: Standard text input with floating label or inline label.
- `<SearchInput />`: Dedicated search box with search icon and clear button.
- `<Select />`: Native styled dropdown select.
- `<Textarea />`: Multi-line text field.
- `<Checkbox />`: High-contrast accessible checkbox.
- `<Radio />`: Single-selection radio button.
- `<Switch />`: Accessible toggle switch.
- `<Slider />`: Range slider with numeric value bubble.
- `<FormField />`: Wrapper uniting label, input control, and error messages.

### 3.6 Overlays & Dialogs
- `<Modal />`: Accessible modal dialog utilizing native `<dialog>` element.
- `<Popover />`: Floating contextual popover container.
- `<Tooltip />`: Hover and focus informative tooltip.

## 4. Usage in `.kiw` Single-File Components

Components can be composed directly in any `.kiw` page or layout using JSX-like component tags:

```html
<Navbar brandName="MyApp" version="v1.0.0" showLangToggle=true />

<main class="container-site py-10">
  <div class="grid grid-cols-1 md:grid-cols-3 gap-6">
    <Stat title="Active Workspaces" value="1,248" change="+14.2%" trend="up" />
    <Stat title="Average Latency" value="8.4ms" change="-2.1ms" trend="up" />
    <Stat title="System Health" value="99.98%" trend="neutral" />
  </div>

  <Card class="mt-8">
    <h3 class="text-lg font-bold mb-4">Quick Deploy</h3>
    <Terminal command="kiw deploy --target cloud" />
    <div class="mt-4 flex gap-3">
      <Button variant="primary">Deploy Now</Button>
      <Button variant="outline">View Plan</Button>
    </div>
  </Card>
</main>
```
