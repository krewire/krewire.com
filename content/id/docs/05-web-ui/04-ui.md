# Komponen Web UI & Design System (`github.com/krewire/ui`)

Import path: `github.com/krewire/ui`

Krewire UI adalah design system neo-brutalist ("pop-brutalist") tanpa dependensi eksternal dan pustaka Single-File Component (`.kiw`) yang dibangun secara native untuk ekosistem Go Krewire.

---

## 1. Filosofi Desain

1. **Miliki Komponen Anda Sendiri (Model Distribusi shadcn)**:
   Komponen berada langsung di dalam direktori `components/` proyek Anda sebagai berkas `.kiw`. Tidak ada bundel JavaScript tersembunyi atau dependensi runtime yang tidak transparan.
2. **Bebas JavaScript Bloat di Runtime**:
   Komponen interaktif memprioritaskan elemen primitif HTML native (`<details>`, `<summary>`, `<dialog>`, elemen form). JavaScript murni (vanilla) yang sangat ringan hanya digunakan ketika interaksi browser memerlukannya (seperti menutup dropdown saat klik di luar area).
3. **Visual Neo-Brutalist Berkontras Tinggi**:
   - Garis batas pop-border khas (`2px` hingga `2.5px` border solid).
   - Bayangan kotak kaku (hard offset shadows `2px 2px`, `4px 4px`, `6px 6px`) tanpa efek blur kabur.
   - Hirarki warna kontras tinggi yang memenuhi standar aksesibilitas WCAG AA/AAA.
4. **Pewarisan Token Deterministik**:
   Seluruh style komponen mewarisi custom properties CSS terpusat. Mengubah nilai token pada `:root` atau kontainer tertentu akan otomatis diterapkan ke seluruh hierarki komponen di dalamnya.

## 2. Sistem Token Desain (`krewire-ui.css`)

Krewire UI mendefinisikan rangkaian token semantik standar:

### Warna Semantik
```css
:root {
  --primary: #39D353;           /* Hijau zamrud cerah */
  --primary-content: #0B1F3B;   /* Teks biru navy malam berkontras tinggi */
  --secondary: #00D1C1;         /* Cyan cerah */
  --secondary-content: #0B1F3B;
  --accent: #FF3B2E;            /* Merah crimson peringatan */
  --accent-content: #ffffff;
  --success: #39D353;
  --warning: #ffb703;           /* Emas amber */
  --error: #FF3B2E;             /* Merah error */
  --info: #00D1C1;              /* Cyan informasi */
}
```

### Permukaan & Inversi Mode Gelap
```css
:root {
  --bg: #FAF8F4;                /* Alabaster cream dasar */
  --bg-2: #f2ede4;              /* Permukaan sedikit terangkat */
  --bg-3: #e8e2d5;              /* Kontainer berbingkai */
  --fg: #0B1F3B;                /* Teks utama navy malam */
  --muted: #57677d;             /* Teks deskriptif sekunder */
  --border: #0B1F3B;            /* Warna border pop-brutalist */
}

:root[data-theme="dark"], html[data-theme="dark"], .dark {
  --bg: #0B1F3B;                /* Latar belakang biru navy malam */
  --bg-2: #112646;              /* Permukaan gelap terangkat */
  --bg-3: #1a3865;              /* Latar kartu */
  --fg: #FAF8F4;                /* Teks cream kontras tinggi */
  --muted: #9ab0ce;             /* Teks gelap diredam */
  --border: #FAF8F4;            /* Border terang pop-brutalist */
}
```

### Border & Bayangan Pop-Brutalist
```css
:root {
  --pop-border: 2.5px solid var(--border);
  --pop-border-thin: 2px solid var(--border);
  --pop-shadow-sm: 2px 2px 0px var(--border);
  --pop-shadow: 4px 4px 0px var(--border);
  --pop-shadow-lg: 6px 6px 0px var(--border);
  --radius: 10px;
}

:root[data-theme="dark"], html[data-theme="dark"], .dark {
  --pop-shadow-sm: 2px 2px 0px var(--primary);
  --pop-shadow: 4px 4px 0px var(--primary);
  --pop-shadow-lg: 6px 6px 0px var(--primary);
}
```

## 3. Registri Komponen (66 Komponen)

Krewire UI menyediakan 66 Single-File Components yang terbagi dalam kategori fungsional:

### 3.1 Navigasi & Struktur
- `<Navbar />`: Header aplikasi utama dengan logo brand, navigasi desktop responsif, dan toggle drawer.
- `<NavMenu />`: Bilah navigasi dengan dukungan menu dropdown interaktif.
- `<Sidebar />`: Navigasi sidebar collapsible untuk portal dokumentasi dan panel admin.
- `<Breadcrumb />`: Navigasi jejak halaman hierarkis.
- `<Tabs />`: Pengalih konten dengan dukungan status aktif persisten.
- `<Pagination />`: Bilah paginasi bernomor lengkap dengan tombol next/prev.
- `<Drawer />`: Panel overlay geser mulus untuk navigasi mobile.
- `<Hamburger />`: Tombol toggle menu hamburger 3 baris teranimasi.
- `<Brand />`: Logo ekosistem scalable dengan badge versi.

### 3.2 Tindakan & Tombol
- `<Button />`: Tombol interaktif inti dengan varian `primary`, `secondary`, `accent`, `outline`, dan `ghost`.
- `<ButtonGroup />`: Rangkaian tombol terkelompok dengan border menyatu dan segment control.
- `<Dropdown />`: Menu interaktif berbasis elemen `<details>` dan `<summary>` dengan penutup otomatis saat klik luar.
- `<ActionMenu />`: Menu tindakan kontekstual ringkas untuk baris tabel dan kartu.
- `<Fab />`: Floating Action Button untuk aksi utama mengambang pada layar.

### 3.3 Umpan Balik & Status
- `<Alert />`: Kotak notifikasi kontekstual untuk status `info`, `success`, `warning`, dan `error`.
- `<Banner />`: Bilah pengumuman lebar penuh dengan tombol tutup.
- `<Toast />`: Notifikasi toast mengambang transien.
- `<Badge />`: Lencana indikator mikro dengan varian warna.
- `<Tag />`: Label kata kunci yang dapat dipilih atau dihapus.
- `<Progress />`: Bilah progres muat determinat dan indeterminat.
- `<Spinner />`: Indikator muat SVG teranimasi yang aksesibel.
- `<Skeleton />`: Placeholder shimmer untuk status konten yang sedang dimuat.
- `<Empty />`: Placeholder status kosong lengkap dengan ikon, pesan, dan tombol CTA.

### 3.4 Tampilan Data & Konten
- `<Card />`: Kontainer kartu terangkat dengan slot header, body, dan footer.
- `<Stat />`: Tampilan metrik numerik dan indikator tren performa.
- `<Table />`: Tabel data responsif dengan opsi baris selang-seling, border, dan efek hover.
- `<Accordion />`: Panel konten yang dapat diperluas/diciutkan dengan navigasi keyboard.
- `<Timeline />`: Alur aktivitas peristiwa vertikal sekuensial.
- `<CodeWindow />`: Jendela terminal bergaya macOS dengan tombol lampu lalu lintas dan tombol salin kode.
- `<Terminal />`: Preview terminal baris perintah tunggal yang ringkas.
- `<Avatar />`: Gambar profil pengguna dengan inisial fallback.
- `<Kbd />`: Indikator visual tombol pintasan keyboard.
- `<Divider />`: Garis pemisah horizontal atau vertikal dengan label opsional.

### 3.5 Formulir & Input
- `<Input />`: Input teks standar dengan label floating atau inline.
- `<SearchInput />`: Kotak pencarian khusus dengan ikon cari dan tombol bersihkan.
- `<Select />`: Dropdown select native bergaya pop-brutalist.
- `<Textarea />`: Bidang input teks multi-baris.
- `<Checkbox />`: Kotak centang aksesibel berkontras tinggi.
- `<Radio />`: Tombol pilihan radio tunggal.
- `<Switch />`: Sakelar toggle switch aksesibel.
- `<Slider />`: Penggeser rentang nilai dengan indikator angka.
- `<FormField />`: Pembungkus terpadu antara label, kontrol input, dan pesan error.

### 3.6 Dialog & Overlay
- `<Modal />`: Kotak dialog modal aksesibel berbasis elemen `<dialog>` native browser.
- `<Popover />`: Kontainer popover kontekstual mengambang.
- `<Tooltip />`: Petunjuk tooltip informatif saat hover dan fokus.

## 4. Penggunaan dalam Single-File Component `.kiw`

Komponen dapat disusun langsung di halaman atau layout `.kiw` apa pun menggunakan tag komponen mirip JSX:

```html
<Navbar brandName="AplikasiSaya" version="v1.0.0" showLangToggle=true />

<main class="container-site py-10">
  <div class="grid grid-cols-1 md:grid-cols-3 gap-6">
    <Stat title="Workspace Aktif" value="1,248" change="+14.2%" trend="up" />
    <Stat title="Rata-rata Latensi" value="8.4ms" change="-2.1ms" trend="up" />
    <Stat title="Kesehatan Sistem" value="99.98%" trend="neutral" />
  </div>

  <Card class="mt-8">
    <h3 class="text-lg font-bold mb-4">Deploy Cepat</h3>
    <Terminal command="kiw deploy --target cloud" />
    <div class="mt-4 flex gap-3">
      <Button variant="primary">Deploy Sekarang</Button>
      <Button variant="outline">Lihat Rencana</Button>
    </div>
  </Card>
</main>
```
