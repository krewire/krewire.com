# Komponen Web UI & Token Desain (`pkg/ui`)

Jalur impor: `github.com/krewire/krewire/pkg/ui`

Paket `ui` menyediakan komponen Single-File Component reusable (`.kiw`), token desain CSS semantik, dan engine peralihan tema (light/dark mode).

---

## Token Desain Kanonikal

Pewarnaan tema dikendalikan sepenuhnya melalui CSS custom properties yang tersemat pada `:root` dan `html[data-theme="dark"]`:

```css
:root {
  --primary: #39D353;
  --primary-content: #0B1F3B;
  --secondary: #00D1C1;
  --accent: #FF3B2E;
  --bg: #FAF8F4;
  --fg: #0B1F3B;
  --muted: #475569;
  --radius: 14px;
}

html[data-theme="dark"] {
  --primary: #39D353;
  --bg: #0B1F3B;
  --fg: #FAF8F4;
  --muted: #8fa2bc;
}
```

---

## Komponen UI Bersama

Tersedia di dalam direktori `pkg/ui/components/`:
- `<Navbar />`: Bar navigasi responsif dengan pengalih tema dan laci mobile.
- `<Sidebar />`: Navigasi bilah samping yang dapat dilipat untuk buku dokumentasi.
- `<Button />`: Tombol aksesibel dengan varian `primary`, `secondary`, dan `outline`.
- `<Terminal />`: Blok pratinjau konsol terminal dengan pewarnaan sintaks.
- `<Drawer />`: Hamparan laci geser untuk perangkat layar sentuh/mobile.\n
