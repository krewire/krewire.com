# Komponen Web UI & Design System (`github.com/krewire/ui`)

Jalur import: `github.com/krewire/ui`  
Engine Go Programatik: `github.com/krewire/krewire/pkg/ui`

**Krewire UI (`kui`)** adalah design system neo-brutalist ("pop-brutalist") tanpa dependensi eksternal dan pustaka Single-File Component (`.kiw`) yang dibangun secara native untuk ekosistem Go Krewire.

Pustaka ini menggabungkan gaya visual pop berbobot tinggi (border solid tegas, bayangan kotak kaku *offset drop shadow*, aksen hijau zamrud dan cyan cerah) dengan elemen primitif HTML semantik dan kompilasi Go murni.

> **Dokumentasi per Komponen**: Untuk halaman dokumentasi individual, spesifikasi properti lengkap, dan contoh kode `.kiw` untuk masing-masing dari 66 komponen, silakan jelajahi [**Katalog Komponen Krewire UI**](/id/docs/ui/components/).

## 1. Mengapa Krewire UI Kebal terhadap "Dependency Hell"

Pada ekosistem frontend tradisional (seperti Node.js, React, atau toolchain berbasis npm), pengembang sering kali terjebak dalam masalah **dependency hell**:
- Pohon `node_modules` yang rapuh dengan ratusan paket transitif.
- Pembaruan minor upstream yang tiba-tiba merusak (*breaking changes*) tampilan atau perilaku aplikasi.
- Ketidakcocokan versi *peer dependencies* dan keterikatan pada bundler rumit (Webpack, Vite, PostCSS).

Krewire UI mengeliminasi risiko *dependency hell* secara fundamental melalui 4 prinsip arsitektur:

1. **Model Distribusi "Copy & Own" (Filosofi shadcn/ui)**:
   - Berkas komponen (seperti `Button.kiw`, `Modal.kiw`, atau `Navbar.kiw`) **bukanlah** pustaka biner tertutup atau paket *black-box*.
   - Komponen disalin langsung ke dalam direktori `components/` milik proyek Anda.
   - Anda memiliki kendali dan kepemilikan penuh atas kode HTML, CSS, dan perilakunya. Pembaruan di tingkat upstream tidak akan pernah merusak aplikasi Anda di lingkungan produksi.
2. **Bebas Runtime NPM / Node.js**:
   - Tidak ada berkas `package.json`, `package-lock.json`, maupun perkakas Node.js yang perlu dipasang.
   - Seluruh komponen `.kiw` dikompilasi oleh engine internal Go dengan kecepatan sub-milidetik.
3. **Nol Dependensi Eksternal di Modul Go**:
   - Pada berkas `github.com/krewire/ui/go.mod`, tidak terdapat satupun baris `require` dependensi pihak ketiga.
   - Pustaka Go hanya mengekspos `embed.FS` standar untuk menyertakan berkas `.kiw` dan stylesheet CSS langsung ke dalam satu binary statis Go (`CGO_ENABLED=0`).
4. **Pemisahan Lapisan Arsitektur yang Tegas (Pyramid Architecture)**:
   - **Layer 2 (`github.com/krewire/krewire/pkg/ui`)**: Pustaka domain Go murni untuk antarmuka, renderer bertipe, token tema, dan pembuat layout aplikasi secara programatik.
   - **Layer 5 (`github.com/krewire/ui`)**: Katalog presentasi berisi template `.kiw` dan stylesheet pop-brutalist.
   - Backend headless atau API service tidak akan pernah terbebani aset template antarmuka grafis.

## 2. Filosofi Desain

1. **Miliki Komponen Anda Sendiri**:
   Komponen hidup berdampingan langsung di direktori `components/` proyek Anda sebagai berkas Single-File Component `.kiw` yang dapat disunting bebas.
2. **Bebas Beban JavaScript Runtime**:
   Komponen interaktif memprioritaskan elemen primitif HTML native (`<details>`, `<summary>`, `<dialog>`, `<form>`). JavaScript murni (vanilla) yang sangat ringan hanya digunakan ketika interaksi browser memerlukannya (misalnya menutup menu saat klik di luar area komponen).
3. **Visual Pop-Brutalist Berkontras Tinggi**:
   - **Pop-Border Tegas**: Garis batas solid `2px` hingga `2.5px` untuk batas elemen yang jelas.
   - **Bayangan Kotak Kaku (*Hard Offset Drop Shadows*)**: Bayangan `2px 2px`, `4px 4px`, dan `6px 6px` tanpa efek blur kabur.
   - **Palet Warna Segar & Berenergi**: Hijau zamrud (`#39D353`), cyan kontras tinggi (`#00D1C1`), dan merah peringatan (`#FF3B2E`).
   - **Kepatuhan Aksesibilitas WCAG AA/AAA**: Rasio kontras teks dan warna diuji ketat untuk keterbacaan optimal.
4. **Pewarisan Token CSS Deterministik**:
   Seluruh style komponen mewarisi custom properties CSS terpusat. Mengubah nilai token pada `:root` atau kontainer tertentu akan otomatis diterapkan ke seluruh hierarki komponen di dalamnya.

## 3. Memulai Penggunaan

### Metode A: Menyalin Komponen Secara Langsung (Direkomendasikan)

Salin berkas komponen yang Anda perlukan dari katalog Krewire UI ke direktori proyek Anda:

```bash
# Contoh: Menyalin komponen interaktif utama ke proyek Anda
mkdir -p ./components
cp path/to/krewire/ui/components/Button.kiw ./components/
cp path/to/krewire/ui/components/Navbar.kiw ./components/
cp path/to/krewire/ui/components/Card.kiw ./components/
cp path/to/krewire/ui/components/Modal.kiw ./components/
cp path/to/krewire/ui/components/Toast.kiw ./components/
```

### Metode B: Menggunakan Go `embed.FS` di Aplikasi Backend

Untuk layanan backend Go yang menyajikan template atau aset CSS secara dinamis:

```go
package main

import (
	"fmt"

	"github.com/krewire/ui/components"
	"github.com/krewire/ui/styles"
)

func main() {
	// Mengakses filesystem embedded yang berisi 66 komponen .kiw
	fs := components.FS

	// Membaca template komponen tertentu
	buttonTemplate, err := components.Get("Button")
	if err != nil {
		panic(err)
	}

	// Mengakses stylesheet CSS kanonikal
	css := styles.CSS
	fmt.Printf("Berhasil memuat template Button (%d byte) dan CSS (%d byte)\n", len(buttonTemplate), len(css))
}
```

### Menghubungkan Stylesheet Design System

Sertakan stylesheet kanonikal yang berisi token desain, reset dasar, dan tata letak primitif pada tag `<head>` halaman HTML Anda:

```html
<link rel="stylesheet" href="/styles/krewire-ui.css">
```

## 4. Sistem Token Desain (`krewire-ui.css`)

Krewire UI mendefinisikan token semantik standar menggunakan CSS custom properties:

### Warna Semantik
```css
:root {
  --primary: #39D353;           /* Hijau zamrud cerah */
  --primary-content: #0B1F3B;   /* Teks biru navy malam berkontras tinggi */
  --primary-hover: #2ecc50;
  --secondary: #00D1C1;         /* Cyan cerah */
  --secondary-content: #0B1F3B;
  --accent: #FF3B2E;            /* Merah crimson peringatan */
  --accent-content: #ffffff;
  --success: #39D353;
  --warning: #ffb703;           /* Emas amber */
  --error: #FF3B2E;             /* Merah peringatan */
  --info: #00D1C1;              /* Cyan informasi */
}
```

### Permukaan & Inversi Mode Gelap (*Dark Mode*)
```css
:root {
  --bg: #FAF8F4;                /* Alabaster cream dasar */
  --bg-2: #f2ede4;              /* Permukaan sedikit terangkat */
  --bg-3: #e8e2d5;              /* Kontainer berbingkai */
  --fg: #0B1F3B;                /* Teks utama navy malam */
  --muted: #57677d;             /* Teks deskriptif sekunder */
  --border: #0B1F3B;            /* Warna border pop-brutalist */
}

:root[data-theme="dark"], html[data-theme="dark"], .dark {
  --bg: #0B1F3B;                /* Latar belakang biru navy malam */
  --bg-2: #112646;              /* Permukaan gelap terangkat */
  --bg-3: #1a3865;              /* Latar kartu gelap */
  --fg: #FAF8F4;                /* Teks cream kontras tinggi */
  --muted: #9ab0ce;             /* Teks terang diredam */
  --border: #FAF8F4;            /* Border terang pop-brutalist */
}
```

### Border & Bayangan Pop-Brutalist
```css
:root {
  --pop-border: 2.5px solid var(--border);
  --pop-border-thin: 2px solid var(--border);
  --pop-shadow-sm: 2px 2px 0px var(--border);
  --pop-shadow: 4px 4px 0px var(--border);
  --pop-shadow-lg: 6px 6px 0px var(--border);
  --radius: 10px;
}

:root[data-theme="dark"], html[data-theme="dark"], .dark {
  --pop-shadow-sm: 2px 2px 0px var(--primary);
  --pop-shadow: 4px 4px 0px var(--primary);
  --pop-shadow-lg: 6px 6px 0px var(--primary);
}
```

### Skala Spasi & Tipografi

- **Skala Spasi Grid**: Dibangun di atas grid inkremental 4px/8px (`--ui-space-1: 4px`, `--ui-space-2: 8px`, `--ui-space-4: 16px`, `--ui-space-6: 24px`, `--ui-space-8: 32px`).
- **Skala Tipografi**:
  - Mikro & Label: `--ui-text-xs` (`11px`), `--ui-text-sm` (`13px`).
  - Paragraf Utama: `--ui-text-base` (`14.5px` / `0.9rem`).
  - Judul & Heading: `--ui-text-lg` (`17px`), `--ui-text-xl` (`20px`), `--ui-text-2xl` (`24px`), `--ui-text-3xl` (`30px`), `--ui-text-4xl` (`36px`).

## 5. Katalog Lengkap 66 Komponen

Krewire UI menyediakan 66 Single-File Components yang terbagi dalam 7 kategori fungsional:

### 5.1 Navigasi & Struktur
- `<Navbar />`: Header responsif utama dengan logo brand, tautan navigasi, dan pemicu drawer mobile.
- `<NavMenu />`: Bilah navigasi dengan dukungan menu dropdown interaktif.
- `<Sidebar />`: Navigasi bilah samping collapsible untuk portal dokumentasi dan dasbor.
- `<Breadcrumb />`: Navigasi jejak hierarkis halaman.
- `<BreadcrumbItem />`: Item individual di dalam jejak navigasi breadcrumb.
- `<Tabs />`: Pengalih tab konten dengan dukungan status aktif persisten.
- `<Pagination />`: Bilah penomoran halaman dengan tombol navigasi sebelum/sesudah.
- `<Drawer />`: Panel overlay geser mulus untuk navigasi tampilan mobile.
- `<Hamburger />`: Tombol toggle menu hamburger 3 baris teranimasi.
- `<Brand />`: Logo ekosistem skalabel dan badge versi.
- `<Head />`: Penyuntik metadata `<head>` kanonikal dan berkas CSS.
- `<Header />`: Banner header bagian halaman.
- `<Footer />`: Footer situs multi-kolom komprehensif dengan hak cipta dan navigasi tautan.

### 5.2 Aksi & Tombol
- `<Button />`: Tombol interaktif inti dengan varian `primary`, `secondary`, `accent`, `outline`, dan `ghost`.
- `<ButtonGroup />`: Kelompok tombol dengan sambungan border terpadu dan segment controls.
- `<Dropdown />`: Menu dropdown yang dibangun di atas elemen native `<details>` dan `<summary>`.
- `<ActionMenu />`: Menu aksi kontekstual ringkas untuk baris tabel dan header kartu.
- `<Link />`: Tautan hiperteks dengan efek hover garis bawah dan keamanan target.
- `<Toggle />`: Tombol toggle interaktif untuk peralihan status biner.
- `<ThemeSwitch />`: Tombol pengalih tema terang/gelap dengan penyimpanan otomatis di localStorage.
- `<LangSwitch />`: Tombol pengalih bahasa untuk aplikasi multi-bahasa (i18n).

### 5.3 Umpan Balik & Status
- `<Alert />`: Banner pemberitahuan kontekstual dengan status `info`, `success`, `warning`, dan `error`.
- `<Banner />`: Bilah pengumuman lebar penuh dengan tombol tutup.
- `<Toast />`: Notifikasi toast mengambang ringan dengan dukungan sembunyi otomatis.
- `<Badge />`: Lencana indikator mikro dengan varian warna semantik.
- `<Tag />`: Label kata kunci yang dapat dihapus atau dipilih.
- `<Progress />`: Bilah indikator progres determinat dan indeterminat.
- `<Spinner />`: Animasi SVG pemutar loader yang ramah pembaca layar.
- `<Skeleton />`: Placeholder kilau (*shimmer*) saat memuat konten.
- `<Empty />`: Placeholder tampilan kosong lengkap dengan ikon, pesan, dan tombol aksi.
- `<Callout />`: Kotak keterangan informatif berbingkai untuk dokumentasi teknis.

### 5.4 Tampilan Data & Konten
- `<Card />`: Kontainer permukaan terangkat dengan slot header, media, isi, dan footer.
- `<Stat />`: Tampilan metrik KPI dengan indikator arah tren (`up`, `down`, `neutral`).
- `<Table />`: Tabel data responsif dengan gaya garis, bingkai, dan efek sorot baris.
- `<Accordion />`: Panel akordion buka-tutup dengan navigasi keyboard yang aksesibel.
- `<Collapse />`: Kontainer konten lipat tunggal.
- `<Timeline />`: Aliran jejak aktivitas kronologis vertikal.
- `<CodeWindow />`: Jendela cuplikan kode bergaya macOS dengan tombol traffic light dan tombol salin.
- `<Terminal />`: Terminal pratinjau perintah baris tunggal ringkas.
- `<Code />`: Cuplikan kode monospace sebaris dengan style konsisten.
- `<Avatar />`: Gambar profil pengguna dengan inisial cadangan otomatis.
- `<Kbd />`: Indikator visual tombol pintasan keyboard.
- `<Divider />`: Garis pemisah horizontal atau vertikal dengan label opsional.
- `<Heading />`: Pembungkus heading semantik (`h1` sampai `h6`) dengan skala tipografi rapi.
- `<Text />`: Pembungkus tipografi untuk teks isi, pengantar, dan deskripsi diredam.
- `<List />`: Daftar tak berurut dan berurut yang tertata rapi.
- `<Ecosystem />`: Grid interaktif untuk memvisualisasikan arsitektur 10 repositori Krewire.

### 5.5 Formulir & Masukan
- `<Form />`: Pembungkus formulir aksesibel dengan penanganan submit dan metode spoofing HTTP.
- `<Input />`: Kolom input teks standar dengan label mengambang atau label sebaris.
- `<SearchInput />`: Kolom pencarian khusus dengan ikon pencarian dan tombol pembersih.
- `<Select />`: Kotak dropdown select bergaya native.
- `<Textarea />`: Kolom input teks multi-baris dengan penyesuaian tinggi otomatis.
- `<Checkbox />`: Kotak centang berkontras tinggi yang aksesibel.
- `<Radio />`: Tombol pilihan radio tunggal.
- `<Slider />`: Bilah geser rentang nilai dengan gelembung angka dinamis.

### 5.6 Lapisan Mengambang (*Overlays & Dialogs*)
- `<Modal />`: Kotak dialog modal aksesibel berbasis elemen native `<dialog>`.
- `<Popover />`: Kontainer popover kontekstual mengambang.
- `<Tooltip />`: Kotak bantuan petunjuk informasi saat disorot kursor atau difokuskan.

### 5.7 Tata Letak Primitif (*Layout Primitives*)
- `<Container />`: Kontainer halaman terpusat yang responsif.
- `<Box />`: Kotak layout serbaguna dengan token padding dan border.
- `<Flex />`: Pembungkus tata letak flexbox fleksibel.
- `<Grid />`: Kontainer CSS Grid dengan kolom dan jarak yang dapat dikonfigurasi.
- `<HStack />`: Tata letak horizontal sejajar dengan spasi seragam.
- `<VStack />`: Tata letak vertikal bertumpuk dengan spasi seragam.
- `<Stack />`: Tata letak bertumpuk terarah dengan pengaturan jarak fleksibel.
- `<Section />`: Bagian halaman semantik selebar layar.
- `<SideMenu />`: Menu bilah samping untuk dasbor administratif.

## 6. Contoh Kode Komponen Utama

### 6.1 Tombol Interaktif (`Button.kiw`)

Komponen `<Button />` menangani tombol biasa maupun tautan hiperteks dengan gaya tombol:

```html
<!-- Tombol aksi utama -->
<Button variant="primary" size="md">
  Deploy Workload
</Button>

<!-- Tautan bergaya tombol dengan ikon -->
<Button href="/docs" variant="outline" size="sm" icon="📖">
  Baca Dokumentasi
</Button>

<!-- Aksi berbahaya dengan fungsi onClick khusus -->
<Button variant="accent" size="sm" onClick="confirmDelete()">
  Hapus Lingkungan
</Button>
```

Properti yang didukung:
- `variant`: `primary`, `secondary`, `accent`, `outline`, `ghost` (standar: `primary`).
- `size`: `sm`, `md`, `lg` (standar: `md`).
- `href`: Ketika diisi, otomatis me-render elemen `<a>` aksesibel dengan style tombol.
- `icon`: Ikon atau emoji pembuka di sisi kiri teks.
- `iconRight`: Ikon atau emoji penutup di sisi kanan teks.
- `disabled`: Menonaktifkan interaksi pengguna.

### 6.2 Kartu Konten (`Card.kiw`)

Komponen `<Card />` menyediakan permukaan terangkat yang tertata rapi:

```html
<Card title="Database Cluster" subtitle="PostgreSQL 17.2 · Produksi" badge="Sehat">
  <div class="space-y-3">
    <p>Penggunaan penyimpanan: <strong>42% (84 GB / 200 GB)</strong></p>
    <Progress value="42" max="100" />
  </div>
  <div slot="footer" class="flex justify-end gap-2">
    <Button variant="ghost" size="sm">Log Sistem</Button>
    <Button variant="outline" size="sm">Cadangkan Sekarang</Button>
  </div>
</Card>
```

### 6.3 Dialog Modal (`Modal.kiw`)

Dibangun menggunakan elemen native HTML `<dialog>` untuk aksesibilitas yang kokoh:

```html
<!-- Tombol Pembuka Modal -->
<Button variant="primary" onClick="document.getElementById('deploy-modal').showModal()">
  Buka Modal
</Button>

<!-- Komponen Dialog Native -->
<Modal id="deploy-modal" title="Konfirmasi Deployment">
  <div slot="body">
    <p>Apakah Anda yakin ingin menerapkan rilis versi <strong>v1.4.0</strong> ke lingkungan produksi?</p>
  </div>
  <div slot="actions">
    <Button variant="ghost" onClick="document.getElementById('deploy-modal').close()">
      Batal
    </Button>
    <Button variant="primary" onClick="executeDeploy()">
      Konfirmasi & Terapkan
    </Button>
  </div>
</Modal>
```

Fitur aksesibilitas bawaan:
- Menekan tombol `Escape` otomatis menutup modal dialog.
- Mengklik area latar belakang (*backdrop*) akan menutup dialog.
- Fokus keyboard otomatis terisolasi di dalam dialog selama modal aktif (*focus trap*).

### 6.4 Statistik Metrik KPI (`Stat.kiw`)

Menampilkan statistik numerik penting lengkap dengan indikator panah tren:

```html
<div class="grid grid-cols-1 md:grid-cols-3 gap-6">
  <Stat label="Total Permintaan" value="4.8M" change="+12.4%" trend="up" subtitle="vs minggu lalu" />
  <Stat label="Rata-rata Latensi" value="1.2ms" change="-0.4ms" trend="up" subtitle="respons p99" />
  <Stat label="Tingkat Error" value="0.001%" change="0.0%" trend="neutral" subtitle="Nol downtime" />
</div>
```

### 6.5 Jendela Kode & Terminal (`CodeWindow.kiw` & `Terminal.kiw`)

Menampilkan blok kode bergaya macOS dengan tombol salin otomatis:

## 7. API Programatik Go (`github.com/krewire/krewire/pkg/ui`)

Untuk layanan backend yang menghasilkan antarmuka dinamis atau merender dasbor server-side rendering (SSR) murni menggunakan kode Go, gunakan pustaka Layer 2 `pkg/ui`:

```go
package main

import (
	"fmt"

	"github.com/krewire/krewire/pkg/ui"
)

func main() {
	// Inisialisasi registri default dengan komponen standar Go
	reg := ui.Default()

	// Merender komponen Badge secara programatik
	html, err := reg.Render("Badge", ui.Badge{
		Text:    "v0.2.3",
		Variant: "primary",
	})
	if err != nil {
		panic(err)
	}

	fmt.Println(string(html))
}
```

### Menyusun Layout Aplikasi dengan `AppBuilder`

```go
builder := ui.NewAppBuilder()
builder.SetTitle("Dasbor · Krewire")
builder.SetTheme(ui.DarkTheme())

builder.AddHeader(ui.Header{
    Brand: "Krewire Cloud",
})

builder.AddCard(ui.Card{
    Title: "Status Kluster",
    Body:  "Seluruh 6 node worker beroperasi normal.",
})

pageHTML := builder.Build()
```

## 8. Standar Aksesibilitas & Praktik Rekayasa Terbaik

- **Landmark Semantik HTML5**: Komponen struktural (`<Navbar>`, `<Sidebar>`, `<Footer>`, `<Section>`) selalu memancarkan tag semantik standar (`<nav>`, `<aside>`, `<footer>`, `<section>`).
- **Dropdown Bebas JavaScript**: Menu dropdown menggunakan elemen HTML murni `<details>` dan `<summary>`, sehingga tetap berfungsi normal meskipun JavaScript browser dinonaktifkan.
- **Indikator Fokus (*Focus Rings*)**: Seluruh elemen interaktif memiliki garis luar fokus berkontras tinggi (`outline: 3px solid var(--primary); outline-offset: 2px`).
- **Gerakan Tereduksi (*Reduced Motion*)**: Seluruh animasi pop menghormati preferensi pengguna `prefers-reduced-motion: reduce`.
- **Kompilasi Pure-Go**: Aplikasi yang menggunakan komponen Krewire UI dikompilasi dengan `CGO_ENABLED=0` menghasilkan binary statis tunggal tanpa ketergantungan pustaka dinamis sistem.
